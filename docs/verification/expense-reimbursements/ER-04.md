Fourteen client tests execute the real client in a synthetic DOM: names/optional notes, Unicode limits, paged literal picker search, parent versions, frozen ambiguous requests, Review latest failures, stale responses, missing-parent create/Back, plain-text detail rows, pending totals, and zero-cost rendering. Codex in-app browser (embedded browser; exact engine version not exposed), localhost synthetic preview, desktop 1280×900 and narrow 390×844. No hosted changes or real bot messages.

Replacement loaded the concurrent note successfully.
